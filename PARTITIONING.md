# Разделы Barnix

Поддерживается MBR с четырьмя основными разделами. GPT, расширенные и логические
разделы не редактируются; для такой таблицы нужен явный режим стирания диска.
Файловая система Barnix — ext2 с блоками 1 КиБ, максимум 5 ГиБ на том.

В установщике после выбора диска доступны:

- **Автоматически стереть диск**: новая MBR, системный ext2 и, для UEFI, ESP 64 МиБ.
- **Автоматически добавить**: новые разделы в свободных промежутках, существующие
  разделы и их содержимое сохраняются. Нужны свободные записи MBR и место.
- **Полностью вручную**: создание/удаление записей, выбор root и ESP. Изменения
  остаются в памяти до итогового подтверждения именем диска.

Ручной редактор:

```
n 1 1 64 efi     # слот, начало МиБ, размер МиБ, тип EFI (UEFI)
n 2 65 256       # ext2
r 2              # выбранный root: будет отформатирован
e 1              # выбранный ESP: будет перезаписан (UEFI)
d 3              # удалить запись
z                # очистить таблицу в плане
w                # принять план
q                # назад
```

Для BIOS ESP не требуется. Bootloader заменяется во всех режимах установки;
первые 1 МиБ используются для него и должны находиться вне разделов. Выбранные
root/ESP форматируются/перезаписываются даже при ручном выборе существующих
разделов. Автодобавление не меняет существующие записи MBR и их boot-флаги.
Стирание означает замену разметки, а не гарантированное удаление каждого байта.

В установленной системе (root):

```
fdisk disk2 list
fdisk disk2 wipe disk2     # явно удалить таблицу; повтор имени обязателен
fdisk disk2 new 1 1 128    # слот 1, начало 1 МиБ, размер 128 МиБ
fdisk disk2 auto 64        # новый ext2-раздел в свободном промежутке
fdisk disk2 delete 2
format disk2p1
mkdir /data
mount disk2p1 /data
unmount /data
```

Имена разделов: `ata0p1`…`ata0p4`, `disk2p1`, `sata0p1`, `nvme0p1` и т. п.
`fdisk` отказывается менять диск с монтированными разделами. `format` также
проверяет пересечение с монтированными томами. Команды управления дисками
кэшируются до входа, поэтому доступны root после размонтирования корня.

## Форматирование из Linux

```sh
sudo make format /dev/sdb1
```

Укажите одно конкретное устройство или раздел вместо `/dev/sdb1`. Команда
стирает прежнюю файловую систему, создаёт ext2 для Barnix и сразу монтирует её
в Linux в `/mnt/barnix-sdb1`. Для целого диска `/dev/sdb` файловая система
создаётся без таблицы разделов. Размер — не более 5 ГиБ, предел Barnix.
Владелец корня смонтированной файловой системы — пользователь, вызвавший sudo.
Сначала размонтируйте устройство; занятые устройства и их разделы отклоняются.
`/dev/*` не является допустимым аргументом: форматируется только одно явно
указанное устройство. Автомонтирование выполняется после форматирования,
настройки монтирования при загрузке Linux не изменяются.
