G++ входит в пакет gcc (BarnStore или sudo brm -S gcc). Файлы C++ — .cpp, .cc, .cxx; Barnix Code выбирает G++ по расширению сам.

Первая программа

#include <iostream>
#include <string>

int main()
{
    std::string name;
    std::cout << "Как тебя зовут? ";
    std::getline(std::cin, name);
    std::cout << "Привет, " << name << "!\n";
}
g++ -std=c++23 -O2 hello.cpp -o hello
./hello
Сборка C++ заметно дольше, чем C: cc1plus — большая программа. Не пугайтесь паузы в полминуты.

Классы

class Shape {
public:
    virtual ~Shape() = default;
    virtual double area() const = 0;
};

class Circle : public Shape {
    double r;
public:
    explicit Circle(double radius) : r(radius) {}
    double area() const override { return 3.14159 * r * r; }
};

#include <memory>
std::unique_ptr<Shape> s = std::make_unique<Circle>(2.0);

КонтейнерКогда
vectorмассив, растущий в конце — по умолчанию
stringстроки (байты UTF-8)
map, unordered_mapсловарь ключ → значение
set, unordered_setмножество без повторов
deque, listвставка в начало и середину
arrayмассив фиксированного размера
