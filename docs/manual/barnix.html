Нативная программа Barnix получает таблицу функций ядра (barnix->...) и работает без Linux-слоя: так устроены Гусь, игры из BarnStore, Barnocraft. Собирает их BDK (Barnix Developer Kit) на компьютере разработчика: make bdk в исходниках Barnix, затем python3 BDK/tools/build.py папка_проекта. Готовый .elf ставится в систему командой sudo brm -U программа.elf.

Окно и игровой цикл (barnix_gfx.h)

#define BARNIX_APP_NAME "demo.elf"
#include <barnix_gfx.h>

static unsigned int pixels[320 * 200];

int main(void)
{
    BgxCanvas screen;
    if (bgx_open(&screen, pixels, 320, 200)) return 1;
    int x = 0;
    for (;;) {
        BgxEvent e;
        while (bgx_poll(&e))
            if (e.type == BGX_PRESS && e.code == BGX_KEY_ESC) { bgx_close(); return 0; }
        if (bgx_key_held(0xcd)) x++;          /* стрелка вправо */
        bgx_clear(&screen, 0x102030);
        bgx_fill(&screen, x, 90, 20, 20, 0xffcc00);
        bgx_text(&screen, 8, 8, "Esc - выход", 0xffffff, 1);
        bgx_present(&screen);
        barnix->sleep_ms(16);
    }
}

Буфер обмена (ABI 14)

Один буфер на всю систему: оболочка, macro, Весёлый Гусь и ваши программы.

barnix->clipboard_set("скопировано", 22);       /* длина в байтах */
char text[1024];
int length = barnix->clipboard_get(text, sizeof text);
unsigned int changed = barnix->clipboard_serial();  /* меняется при каждом копировании */

Программа внутри другой (ABI 13–14)

barnix->run() запускает программу и собирает её вывод; run_area(x, y, w, h) перед этим показывает её в прямоугольнике вашего кадра — так Gouse Prompt и BarnStore запускают программы в своём окне.
