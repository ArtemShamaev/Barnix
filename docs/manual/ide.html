Barnix Code

Редактор кода в духе VS Code для Весёлого Гуся

ГлавнаяCC++PythonNovaJavaHTML/CSS/JSBarnix APIОболочка и brm

Слева — панель действий: Проводник (папка проекта), Поиск по файлам и Запуск. Сверху вкладки открытых файлов, справа мини-карта, внизу панель «Проблемы / Вывод / Терминал» и синяя строка состояния. Открытые файлы и папка запоминаются; несохранённые правки ждут в памяти до следующего открытия окна.

Подсказки (IntelliSense)

Пока вы печатаете, под курсором появляется список: ключевые слова и функции языка, слова из файла, а после точки — члены модуля или объекта (math., os.path., "текст"., std::). Буквы можно пропускать: prt найдёт print. Над вызовом функции показываются её параметры.

Ctrl+Spaceпоказать подсказки
↑ / ↓, PgUp / PgDnвыбор
Tab или Enterвставить (функция — со скобками, шаблон — с отступами: for, def, if, main…)
Escзакрыть

Отладчик Python

F9 или щелчок по полю с номерами строк ставит красную точку останова. F5 в Python-файле запускает отладчик: слева исходник со стрелкой на текущей строке, ниже переменные, стек вызовов и вывод программы. Команды пишутся внизу:

nследующая строка
s, oвойти в функцию, выйти из неё
cпродолжить до точки останова
b 12поставить или убрать точку на строке 12 (точки возвращаются в редактор)
p выражение, w выражениепосчитать; следить за значением на каждом шаге
q, Enterостановить; повторить прошлую команду

Скобки и кавычки закрываются сами, парная скобка обводится рамкой, Enter сохраняет отступ. Подсветка: C, C++, Python, Nova, JavaScript, HTML, CSS, JSON, Markdown, Shell.

Если компилятора или Python нет, Barnix Code откроет BarnStore с нужным пакетом.
