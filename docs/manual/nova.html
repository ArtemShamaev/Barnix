int fib(int n):
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)

void main():
    var name = "World"
    print("Hello, " + name + "!")
    for i in 0..10:
        print("fib(" + i + ") = " + fib(i))

Сборка и запуск

Компилятор Nova сам работает на JDK 21, поэтому собирают на компьютере разработчика:

./nova build hello.nova -o hello.jar   # на Linux/Windows с JDK 21

Готовый JAR запускается в Barnix виртуальной машиной BJVM:

java -jar hello.jar
nova run /usr/share/nova/examples/hello.jar   # примеры

В Barnix Code можно писать .nova-файлы; F5 запускает собранный рядом .jar.

Классы

class Shape:
    string name

    init(string name):
        this.name = name

    double area():
        return 0.0

class Circle(Shape):
    double r

    init(double r):
        super("круг")
        this.r = r

    double area():
        return 3.14159 * r * r
