С чего начать

  1. Нет компилятора? Откройте BarnStore на рабочем столе Гуся и установите gcc (или в Gouse Prompt: sudo brm -S gcc).
  2. Откройте Barnix Code, создайте файл (Ctrl+N), сохраните его (Ctrl+S) и нажмите F5.
  3. Справка по языку текущего файла открывается клавишей F1.
