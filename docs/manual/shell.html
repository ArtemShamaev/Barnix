Где вводить команды

В текстовой оболочке после входа или в Gouse Prompt в Весёлом Гусе. В Prompt любые программы — даже игры и редакторы — работают прямо в его окне; full программа отдаёт ей весь экран.

Пакеты: brm

sudo brm -Sy            обновить список пакетов
brm -Ss игра            поиск
sudo brm -S gcc gsnake  установить
sudo brm -Syu           обновить всю систему
brm -Q                  что установлено;  brm -Ql gcc  его файлы
sudo brm -R gsnake      удалить

В Весёлом Гусе всё то же делает BarnStore: категории, поиск, кнопки «Установить», «Удалить», «Обновить всё». Системные программы Barnix тоже пакеты: так они обновляются.

sudo

sudo команда выполняет её от имени root, спросив пароль. В Gouse Prompt пароль запоминается на 5 минут.
