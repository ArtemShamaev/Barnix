Barnix запускает готовые JAR-файлы с байткодом Java 8 (класс-файлы версии до 52). Компилятор javac в системе не работает: собирайте программу на компьютере разработчика (javac --release 8) или пишите на Nova, а сюда переносите .jar.

java -jar game.jar
java -cp classes Main

Minecraft Alpha

В Весёлом Гусе есть Лаунчер Alpha: положите mc.jar (клиент a1.2.6) и, если есть, mod.jar в папку игры (по умолчанию /mc), введите ник и нажмите «Играть». Миры и настройки игры лежат в /mc/minecraft.

Пример

public class Main {
    public static void main(String[] args) {
        StringBuilder sb = new StringBuilder();
        for (int i = 1; i <= 5; i++) sb.append(i).append(' ');
        System.out.println("Числа: " + sb);
    }
}
javac --release 8 Main.java          # на компьютере разработчика
jar cfe main.jar Main Main.class
java -jar main.jar                   # в Barnix

Что есть в BJVM

  • интерпретатор байткода, сборщик мусора, потоки (Thread, synchronized);
  • основные классы java.lang, java.util (коллекции), java.io (файлы);
  • LWJGL 2 и OpenGL для игр — цель: запуск Minecraft Alpha с модами.

Чего нет

  • Swing и AWT-окон, сети через java.net, JIT-компиляции.
