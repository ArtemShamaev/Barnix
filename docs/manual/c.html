Установка

GCC — это пакет gcc (около 60 МБ скачивания, 180 МБ на диске). Установите его в BarnStore или командой sudo brm -S gcc. Нужен установленный Barnix (не Live CD) и от 1,5 ГБ памяти.

Первая программа

#include <stdio.h>

int main(void)
{
    printf("Привет, Barnix!\n");
    return 0;
}

В Barnix Code: сохраните файл как hello.c и нажмите F5 — он соберётся и запустится в терминале внизу. В Gouse Prompt или в оболочке:

gcc hello.c -o hello
./hello
Программы собираются статически (-static добавляется сам): в Barnix нет динамического загрузчика. Готовая программа — обычный ELF для Linux i386, Barnix запускает его сам.

Ввод и вывод

int age;
printf("Сколько лет? ");
if (scanf("%d", &age) == 1) printf("Через год: %d\n", age + 1);

char line[100];
fgets(line, sizeof line, stdin);   // целая строка

Ввод с клавиатуры идёт строками: текст виден по мере набора, Backspace стирает, Ctrl+V вставляет из буфера обмена, Enter отправляет строку программе.

Файлы

FILE *f = fopen("notes.txt", "w");
if (!f) { perror("notes.txt"); return 1; }
fprintf(f, "строка %d\n", 1);
fclose(f);

f = fopen("notes.txt", "r");
char buffer[256];
while (fgets(buffer, sizeof buffer, f)) printf("%s", buffer);
fclose(f);

Обычный пользователь пишет в свою папку /home/ИМЯ и в /tmp; системные папки — только root.

Что пока не работает

  • динамические библиотеки (.so) и dlopen;
  • потоки работают ограниченно, сети через сокеты Linux нет (для сети и графики — Barnix API);
  • одновременно живут до 3 процессов (fork, system).

Окно, графика и звук в C — это нативные программы Barnix (BDK).
